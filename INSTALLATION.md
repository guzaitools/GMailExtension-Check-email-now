# Quick Installation Guide

## Install the Extension

1. **Download** this folder to your computer
2. **Open Chrome** and go to `chrome://extensions/`
3. **Turn on Developer mode** (toggle in top-right)
4. **Click "Load unpacked"** and select this folder
5. **Done!** The extension is now installed

## First-Time Setup

1. **Open Gmail** in your browser
2. **Go to Settings** (gear icon) → "See all settings"
3. **Click "Accounts and Import"** tab
4. **Verify POP3 accounts** are listed under "Check mail from other accounts"
5. **Test manually** by clicking "Check mail now" once

## Start Using

- Look for the **"Check POP3 Mail"** button in Gmail's toolbar
- Or click the extension icon in Chrome's toolbar
- Or right-click on Gmail pages for context menu

## Need Help?

- Make sure POP3 accounts are configured in Gmail first
- Try refreshing Gmail if button doesn't appear
- Check that extension is enabled in `chrome://extensions/`

That's it! You can now check your POP3 mail with one click.
